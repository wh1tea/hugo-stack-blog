每个数据结构都是为了解决特定问题而出现的：数组解决连续内存的随机访问，链表解决动态插入，树解决层级关系。理解"为什么需要它"，比记住效率数值更重要。本文按这条线索梳理复杂度分析与核心数据结构，作为入门知识框架。

## 复杂度分析

复杂度分析用大 O 表示法描述算法执行时间或额外空间随数据规模增长的趋势，忽略常数项和低阶项，只保留增长最快的部分。

### 时间复杂度

| 复杂度     | 名称       | 示例                   |
| ---------- | ---------- | ---------------------- |
| O(1)       | 常数阶     | 数组随机访问           |
| O(log n)   | 对数阶     | 二分查找               |
| O(n)       | 线性阶     | 遍历数组               |
| O(n log n) | 线性对数阶 | 归并排序、快速排序     |
| O(n²)      | 平方阶     | 冒泡排序、嵌套循环     |
| O(2ⁿ)      | 指数阶     | 递归斐波那契（未优化） |
| O(n!)      | 阶乘阶     | 旅行商问题暴力解       |

两条计算规则：加法法则取量级最大的那段代码，乘法法则把嵌套循环的内外层复杂度相乘。

### 空间复杂度

衡量运行时占用的额外存储：就地排序是 O(1)，归并排序需要额外数组是 O(n)，二维辅助数组是 O(n²)。时间与空间通常是权衡关系——缓存用空间换时间，内存受限环境则反过来。

## 数据结构的分类

### 逻辑结构

逻辑结构描述数据元素之间的关系。

线性结构是一对一排列：

| 结构     | 特点                                      | 常见操作         |
| -------- | ----------------------------------------- | ---------------- |
| **数组** | 连续内存，随机访问 O(1)，插入/删除 O(n)   | 遍历、修改、排序 |
| **链表** | 非连续内存，随机访问 O(n)，插入/删除 O(1) | 遍历、反转、合并 |
| **栈**   | 后进先出（LIFO）                          | 入栈、出栈、栈顶 |
| **队列** | 先进先出（FIFO）                          | 入队、出队、队首 |

非线性结构是一对多或多对多：树、堆描述层级关系，哈希表是键值映射，图由节点和边构成，反映复杂网络关系。

### 物理存储结构

所有数据结构本质上都是数组、链表或二者的组合：

| 数据结构 | 可用实现方式                       |
| -------- | ---------------------------------- |
| 栈       | 数组（顺序栈）/ 链表（链式栈）     |
| 队列     | 数组（循环队列）/ 链表（链式队列） |
| 哈希表   | 数组 + 链表（链地址法）            |
| 树 / 堆  | 数组（堆）、链表（二叉树）         |
| 图       | 数组（邻接矩阵）/ 链表（邻接表）   |

数组初始化后长度不可变，属于静态结构；链表可在运行时调整长度，属于动态结构。数组通过重新分配内存也能变长，具备一定动态性。

## 核心数据结构详解

### 数组

连续内存空间，每个元素大小相同。随机访问 O(1)，插入删除需移动元素 O(n)。动态数组（C++ vector、Java ArrayList）自动扩容。用于索引查找、矩阵运算，也是实现其他结构的基础。

### 链表

节点通过指针串联，内存不连续。已知位置时插入删除 O(1)，随机查找 O(n)。分单链表、双向链表、循环链表。用于 LRU 缓存、哈希表链地址法、文件系统 FAT。

### 栈

后进先出，只能从一端操作。核心操作是 push、pop、top。用于函数调用栈、括号匹配、表达式求值、浏览器后退。

### 队列

先进先出，队尾入、队首出。变体有循环队列（解决假溢出）、双端队列、优先队列（基于堆）。用于 BFS、消息队列、任务调度。

### 哈希表

哈希函数把键映射到数组索引，实现近乎 O(1) 的查找。冲突解决有链地址法、开放寻址法、再哈希法。负载因子超过阈值触发扩容。用于数据库索引、缓存、字典实现。

### 树

分层结构，每个节点有父节点和若干子节点。二叉树每节点最多两个子节点；二叉搜索树满足左 < 根 < 右，中序遍历有序；AVL 树与红黑树是自平衡 BST，保证最坏 O(log n)；堆分大顶堆和小顶堆，用于优先队列。遍历方式有前序、中序、后序、层序。

### 图

由顶点和边组成，分有向/无向、加权/无权。稠密图用邻接矩阵，稀疏图用邻接表。经典算法包括 DFS/BFS、Dijkstra/Bellman-Ford/Floyd 最短路径、Kruskal/Prim 最小生成树、Kahn 与 DFS 后序拓扑排序。

## 算法学习路线

1. **基础**（1–2 周）：复杂度分析；数组、链表、栈、队列的增删改查。
2. **核心**（3–6 周）：哈希表、双指针、滑动窗口；二叉树遍历与递归、堆与优先队列；快排、归并、堆排。
3. **进阶**（7–10 周）：动态规划、回溯、贪心；图论基础；并查集、字典树、线段树。

从查字典（哈希/二分）、扑克整理（插入排序）、货币找零（贪心/动态规划）这类场景切入，先理解问题，再写代码。

## 结语

复杂度分析是衡量算法好坏的客观标准，数组和链表是所有数据结构的两大基石。线性结构侧重顺序操作，非线性结构处理更复杂的映射与关系。带着问题去学，比死记效率数值更容易建立长期记忆。
