整数线性规划（Integer Linear Programming, ILP）在线性约束下求目标函数的最值，并要求部分或全部决策变量取整数。它比线性规划难得多，因为可行域不再连续。本文按四层知识结构给出从入门到能上手的路径，并附一份 1–2 周的线性规划速成纲要。

## 四层知识结构

### 第一层：数学与编程基础

- **线性代数**：最关键。矩阵向量运算、线性方程组求解、凸集与凸锥的基本概念，用于表达多变量问题和理解解空间结构。
- **高等数学**：理解多元函数与梯度即可，ILP 多数方法不依赖连续求导。
- **概率统计**：期望、方差、随机抽样。主要在随机舍入等随机算法中出现。
- **编程**：至少会一门语言（推荐 Python）的 `if`、`for`、递归。实践中靠求解器（OR-Tools、CPLEX、Gurobi）解算，不手算。

### 第二层：线性规划前导

这是最直接的理论前提，必须先学好线性规划。

- **几何解释**：可行域是凸多面体，最优解在顶点上。
- **求解算法**：单纯形法（理解迭代逻辑）、内点法（了解思想）。
- **理论基石**：对偶理论必学，它提供整数规划中至关重要的上下界；互补松弛定理与灵敏度分析同属这一层。
- **图论与网络流**：图、树、最短路径、最大流最小割。TSP、指派问题本身就是图论问题。

### 第三层：整数规划特有概念

- **模型分类**：纯整数规划、混合整数规划、0-1 整数规划。
- **难点来源**：可行域离散、不连续，不能沿边移动寻优。
- **经典问题**：背包、指派、旅行商、设施选址，它们是验证算法的演练场。
- **建模技巧**：用二进制变量表达逻辑约束（"如果……则……"）、分段线性函数、固定成本。

### 第四层：求解算法

必修两个：

- **分支定界法**：求解器的灵魂算法，理解松弛、分支、定界、剪枝四步。
- **割平面法**：添加线性不等式切掉松弛问题的非整数最优解。

进阶了解：拉格朗日松弛（把难约束放进目标函数，提供更紧的界）、列生成（处理变量极多的大规模问题）、启发式算法（遗传、模拟退火，快速得到可行解但不保证最优）。

## 线性规划速成纲要

1–2 周完成，每天 1–2 小时。

### 基本概念（0.5 天）

标准形式 `min c^T x` s.t. `Ax = b`, `x ≥ 0`，任何 LP 都可转化为标准形。可行域是凸多面体，最优解若存在必在顶点取得。练习画 2 变量 LP 的图，标出顶点与目标函数移动方向。

### 建模（1 天）

决策变量、目标函数、约束条件三件套。手写生产计划、营养配餐、运输问题各一个模型。注意变量无约束时可拆为正负两部分，`≥` 约束可加松弛变量转为等式。

### 单纯形法（2 天）

几何上是从一个顶点沿边移动到更好的相邻顶点，代数上用单纯形表识别进基与离基变量。初始基可行解不易得到时（有 `≥` 或等式约束），用两阶段法或大 M 法。退化与循环知道可能发生即可，实际求解器有防循环策略。

用手算跑一遍小例子：

```text
max z = 3x1 + 2x2
s.t. x1 + x2 ≤ 4
     2x1 + x2 ≤ 5
     x1, x2 ≥ 0
```

### 对偶理论（1.5 天）

原始最大化对应对偶最小化，约束方向与变量符号存在对称关系。弱对偶给出对偶目标 ≤ 原始目标，强对偶保证两者最优值相等，互补松弛用于验证最优性与推导割平面。这一层直接解释"为什么线性松弛给出的界对整数规划有用"。

### 灵敏度分析（1 天）

影子价格是资源约束右端项增加 1 单位时目标函数的变化量，等于对偶变量的值。理解概念即可，不必背公式。它在整数规划预处理中帮助固定变量或生成割平面。

### 调用求解器（1 天）

选一个工具：PuLP（语法接近数学表达）、OR-Tools（支持 LP / IP / CP）、Pyomo（更专业）。PuLP 示例：

```python
from pulp import *
prob = LpProblem("example", LpMaximize)
x1 = LpVariable("x1", lowBound=0)
x2 = LpVariable("x2", lowBound=0)
prob += 3*x1 + 2*x2
prob += x1 + x2 <= 4
prob += 2*x1 + x2 <= 5
prob.solve()
print(value(x1), value(x2), value(prob.objective))
```

写三个不同 LP（生产、运输、投资组合）求解并对照手算结果。

### 与整数规划衔接（0.5 天）

去掉整数约束得到 LP 松弛，其最优值是整数规划的一个界。LP 可行域是凸集，IP 可行域是离散点，不能沿边移动，这是 IP 难的根源。分支定界法就是求解 LP 松弛、分支、利用界剪枝。

## 时间安排

| 天   | 内容                       | 实践任务                   |
| :--- | :------------------------- | :------------------------- |
| 1    | 基本概念、标准形           | 画 2D 图，翻译成标准形     |
| 2    | 建模生产/营养/运输问题     | 手写 3 个完整 LP 模型      |
| 3    | 单纯形法（表格）           | 手算 2 个小例子            |
| 4    | 两阶段法 / 大 M            | 一个带 `≥` 的例子          |
| 5    | 对偶理论（写对偶、弱对偶） | 给定原始求对偶，验证弱对偶 |
| 6    | 强对偶、互补松弛           | 验证互补松弛条件           |
| 7    | 灵敏度 / 影子价格          | 分析右端项变化             |
| 8    | Python + PuLP 实践         | 求解 3 个模型并解读输出    |
| 9    | 小结与 IP 衔接             | 复习 LP 松弛概念           |

每天 1–2 小时；周末加倍可压缩到 1 周。
