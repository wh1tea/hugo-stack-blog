> 如果你在桌面或文件夹上右键时，发现菜单里多了一个 “Armoury Crate” 或 “游戏库” 选项，这通常是因为安装了华硕的奥创智控中心（Armoury Crate）软件。这个选项可能会让右键菜单变得冗长，影响操作效率。本文将提供三种不同的清理方法，你可以根据自己是否仍在使用该软件来选择最适合的方式。

## 概述

**Armoury Crate** 是华硕为其 ROG、TUF 等系列产品开发的一体化系统控制软件，用于管理灯光、性能模式、驱动更新等。安装后，它默认会在系统右键菜单中添加一个快捷入口，方便快速打开软件。但如果你已经不再使用它，或者觉得这个菜单项多余，可以按照以下方法将其移除。

本文介绍的方法按操作难度和适用场景排列：

- **方法一**：在 Armoury Crate 软件内部关闭（适合仍在使用该软件的用户）
- **方法二**：通过注册表编辑器彻底删除（适合已卸载软件但仍有残留的用户）
- **方法三**：使用第三方右键管理工具（操作最简单，适合所有用户）

请根据你的实际情况选择其中一种即可。

## 问题现象

右键菜单中出现的 “Armoury Crate” 或 “游戏库”（gamelibrary）选项，通常位于菜单的中下部，点击后会直接打开 Armoury Crate 主界面。这个选项由华硕的 shell 扩展注册在系统注册表中，即使卸载了主程序，有时注册表键值仍会残留，导致菜单项依然存在。

## 解决方法

### 方法一：在 Armoury Crate 软件内直接关闭（推荐保留软件的用户）

如果你目前仍在使用 Armoury Crate，并且不希望卸载它，那么通过软件自带的设置来关闭右键菜单是最安全、最干净的做法。步骤如下：

1. 打开 **Armoury Crate** 软件（可以从开始菜单或桌面快捷方式启动）。
2. 在左侧菜单栏中找到 **设置**（通常是一个齿轮图标），点击进入。
3. 切换到 **游戏库（Game Library）** 选项卡。
4. 找到 **快捷菜单** 或 **右键菜单** 相关的开关，将其 **关闭** 或 **取消勾选**。
5. 关闭设置窗口，右键菜单中的选项会立即消失（有时需要重启资源管理器或重新登录）。

这种方法不会影响软件的其他功能，日后如有需要也可以随时重新开启。

> 其他：官方卸载工具在[Armoury Crate Uninstall Tool](https://armoury-crate.com/#download)

### 方法二：通过注册表编辑器彻底删除（适合已卸载软件但仍有残留）

如果你已经通过控制面板或卸载工具移除了 Armoury Crate，但右键菜单项依然顽固存在，则可能是注册表中的对应键值没有被清理。此时可以手动删除注册表项，操作如下：

> **警告**：修改注册表存在风险，请务必按照步骤操作，不要删除无关项。建议提前备份注册表。

1. 按下键盘上的 **Win + R** 组合键，打开“运行”对话框。
2. 输入 `regedit` 并按下回车，打开注册表编辑器。
3. 在顶部的地址栏中复制并粘贴以下路径，然后按回车快速定位：

   ```bash
   HKEY_CLASSES_ROOT\Directory\Background\shell\gamelibrary
   ```

4. 在左侧导航树中找到名为 **gamelibrary** 的文件夹（即 shell 下的子项）。
5. 鼠标右键点击该文件夹，选择 **删除**，在弹出的确认提示中点击“是”。
6. 关闭注册表编辑器，**重启电脑**（或重启资源管理器），右键菜单中的选项就会消失。

> **备选路径**：如果上述路径找不到，也可以检查以下位置是否存在类似项：
>
> - `HKEY_CLASSES_ROOT\Directory\shell\gamelibrary`
> - `HKEY_CURRENT_USER\Software\Classes\Directory\Background\shell\gamelibrary`
>
> 不同版本的华硕软件可能注册位置略有差异，但通常都在 `shell` 下以 `gamelibrary` 命名。

### 方法三：使用第三方右键管理工具（操作最简单，新手友好）

如果你不想手动操作注册表，或者对系统底层修改不太放心，可以使用专门的右键菜单管理工具。这些工具提供图形化界面，可以轻松启用/禁用任意菜单项。

推荐以下两种常用工具：

- **[火绒安全软件](https://www.huorong.cn/)**：内置“右键管理”功能，可单独禁用 Armoury Crate 相关项，操作直观，且免费。
- **[Geek Uninstaller](https://geekuninstaller.com/)**：虽然主要用于卸载，但其“右键菜单管理”模块也能快速删除不需要的项。

**通用操作步骤**（以火绒为例）：

1. 下载并安装火绒安全软件。
2. 打开火绒主界面，点击左侧的 **安全工具**。
3. 找到并点击 **右键管理** 工具。
4. 在列表中找到与 `Armoury Crate` 或 `gamelibrary` 相关的条目。
5. 点击右侧的 **禁用** 或 **删除** 按钮即可。

使用这类工具的好处是操作简单，且支持一键恢复，即便误操作也能轻松撤回。

## 常见问题与建议

**Q：我怎么知道自己是否还安装了 Armoury Crate？**  
A：可以在开始菜单中搜索“Armoury Crate”，如果找到图标则说明已安装。或者查看任务栏右下角是否有奥创的托盘图标。

**Q：我使用的是华硕的 ROG 还是 TUF / 飞行堡垒，有区别吗？**  
A：Armoury Crate 适用于华硕全系游戏产品（ROG、TUF、飞行堡垒等），右键菜单的行为是一致的，上述方法通用。不过部分较老机型可能使用的是旧版“ROG Gaming Center”，但处理方式类似。

**Q：删除注册表项后，会影响系统的其他功能吗？**  
A：只删除 `gamelibrary` 这一项，不会影响系统正常运行。但如果你误删了其他键值，可能会导致软件异常。建议严格按照提供的路径操作。

**Q：如果我未来又想恢复这个菜单项怎么办？**  
A：如果使用方法一关闭，重新开启即可；如果使用方法二删除，需要重新安装 Armoury Crate 才能恢复；如果使用方法三禁用，在工具中重新启用即可。

## 结语

右键菜单中的 Armoury Crate 选项虽然不至于影响系统性能，但对于追求简洁操作的用户来说确实是个累赘。选择最适合你的方法清理掉它，能让你的 Windows 体验更加清爽。如果你在执行过程中遇到任何问题，欢迎在评论区留言讨论。
