一群人里至少有两人生日相同，需要多少人？直觉常答 183（365 的一半），正确答案是 23。本文说明这个反直觉结论怎么来的，给出可复算的推导与代码，读完能自己验证任意人数下的概率。

## 问题到底在问什么

关键区别：

- **指定两个人**生日相同：概率恒为 $1/365 \approx 0.27\%$，与人数无关。
- **一群人里存在某一对**生日相同：人数越多，可配对的组合越多，概率迅速上升。

生日悖论问的是后者[^1]。它不是「某人和你同生日」，而是「任意两人之间」。

## 先算反面

直接算「至少一对相同」很麻烦，改算它的补集——**所有人生日都不同**。

第一个人随便哪天都行；第二人要不撞上第一人，只剩 $364/365$；第三人剩 $363/365$，依此类推。$n$ 个人全部不同的概率是：

$$
P(\text{都不同}) = \frac{365}{365} \times \frac{364}{365} \times \cdots \times \frac{365-n+1}{365}
$$

于是至少一对相同的概率：

$$
P(\text{相同}) = 1 - P(\text{都不同})
$$

## 为什么下降得这么快

每加一个人，就多出「他与前面所有人都不撞」这一重约束。乘法累积下，$P(\text{都不同})$ 衰减得比线性直觉快得多：

| 人数 $n$ | $P(\text{都不同})$ | $P(\text{至少一对相同})$ |
| -------: | -----------------: | -----------------------: |
|       10 |              88.3% |                    11.7% |
|       20 |              58.9% |                    41.1% |
|       22 |              52.4% |                    47.6% |
|       23 |              49.3% |                **50.7%** |
|       30 |              29.4% |                    70.6% |
|       50 |               3.0% |                    97.0% |
|       70 |              0.08% |                   99.92% |

$n=22$ 时还差一点，$n=23$ 首次越过 50%。

## 组合视角

另一个等价解释：$n$ 个人能组成 $\binom{n}{2} = n(n-1)/2$ 对。$n=23$ 时有

$$
\binom{23}{2} = \frac{23 \times 22}{2} = 253
$$

对。虽然每对相同的概率只有 $1/365$，但 253 对里「至少中一次」的期望已经不小。用 $1-(1-1/365)^{253}$ 粗略估计约 50%，与精确值接近——差异来自各对并不独立。

## 用 Python 验证

```python
def birthday_prob(n: int, days: int = 365) -> float:
    """n 人中至少两人生日相同的概率。"""
    p_all_diff = 1.0
    for i in range(n):
        p_all_diff *= (days - i) / days
    return 1 - p_all_diff

for n in (10, 20, 22, 23, 30, 50, 70):
    print(f"n={n:2d}  P={birthday_prob(n):.4f}")
```

输出与上表一致，`n=23` 时约 `0.5073`。

## 结语

23 是「至少一对相同」超过 50% 的最小人数。反直觉的根源是把问题误当成「指定两人相同」：前者随 $n$ 呈平方级增长的对数，后者恒为 $1/365$。记住补集算法——先算「全都不同」再取反，是这类「至少一个」问题的通用套路。
