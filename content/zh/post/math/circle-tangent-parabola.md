在第一象限的单位正方形 $[0,1]^2$ 内找一个圆，同时与 $x = 0$、$y = 1$ 和抛物线 $y = x^2$ 相切。正确解法与常见错解的分水岭在于相切条件怎么写：半径必须沿法线。

## 题目

正方形的四个顶点是 $(0,0)$、$(1,0)$、$(1,1)$、$(0,1)$。求半径 $r > 0$ 的圆，满足：

- 圆心在正方形内部；
- 与 $x = 0$ 相切；
- 与 $y = 1$ 相切；
- 与抛物线 $y = x^2$ 相切，切点在第一象限内。

## 圆心由前两个相切条件确定

与 $x = 0$ 相切且圆心在内部，圆心横坐标 $h = r$；与 $y = 1$ 相切且圆心在其下方，纵坐标 $k = 1 - r$。所以圆心是 $C = (r, 1 - r)$，圆方程为

$$(x - r)^2 + (y - (1 - r))^2 = r^2$$

## 相切条件沿法线写

设切点为 $T = (x, x^2)$，$0 < x < 1$。抛物线在 $T$ 处的法向量是 $(-2x, 1)$。相切意味着 $T$ 到 $C$ 的向量与这条法线共线，且长度等于 $r$：

$$\overrightarrow{TC} = (r - x,\ 1 - r - x^2) = \lambda(-2x,\ 1)$$

第二个分量给出 $\lambda = 1 - r - x^2$，代入第一个分量并整理：

$$r(1 - 2x) = x(2x^2 - 1) \tag{1}$$

再由 $|TC| = r$，即 $\lambda^2 (4x^2 + 1) = r^2$：

$$r^2 = (1 - r - x^2)^2 (4x^2 + 1) \tag{2}$$

(1) 式右端必须为正（$r > 0$），这把 $x$ 限制在 $(0.5, 1/\sqrt{2})$ 内。

## 数值求解

(1)(2) 消去 $x$ 得到 $r$ 的方程

$$2048r^7 - 7264r^6 + 7496r^5 - 2363r^4 - 1518r^3 + 1638r^2 - 594r + 81 = 0$$

它在 $(0, 1)$ 内只有一个根 $r \approx 0.361027030$；另外两个实根 $-0.609799$ 与 $2.123431$ 都不满足「圆心在正方形内部」。

直接对 (1)(2) 做二分不必消元：

```python
import math

def radius_at(x: float) -> float:
    """Radius as a function of the tangency point's x (equation 1)."""
    return x * (2 * x * x - 1) / (1 - 2 * x)

def gap(x: float) -> float:
    """Difference between the two sides of equation 2."""
    r = radius_at(x)
    return r - abs(1 - r - x * x) * math.sqrt(4 * x * x + 1)

lo, hi = 0.63, 0.66          # r < 1/2 on this interval, so the circle fits the square
for _ in range(100):
    mid = (lo + hi) / 2
    if gap(lo) * gap(mid) <= 0:
        hi = mid
    else:
        lo = mid

x = (lo + hi) / 2
print(f"x = {x:.9f}, r = {radius_at(x):.9f}")   # x = 0.646631769, r = 0.361027030
```

`abs` 来自 (2) 式的平方，实际解处 $\lambda = 1 - r - x^2 > 0$。

## 结果校验

- $|TC| - r$ 约为 $10^{-15}$，半径条件在浮点精度内成立；
- 半径向量与法线向量的叉积为 $0$，两者确实共线；
- $2r \approx 0.722 < 1$，圆完全落在正方形内；
- 在圆上采样，$y - x^2$ 的最小值出现在切点（约 $10^{-14}$），其余位置为正，圆与抛物线只在一个点接触。

## 一个容易犯的错误

另一种做法取 $F(x, y) = y - x^2$，在横坐标等于 $r$ 处算圆心到该点切线的距离，并令它等于半径：

$$\frac{1 - r - r^2}{\sqrt{4r^2 + 1}} = r$$

这等于假设切点的横坐标恰好是 $r$，也就是假设半径竖直。但相切时半径必须沿法线 $(-2x, 1)$，而 $x$ 一般不等于 $r$。

按这个做法得到的 $r = (\sqrt{5} - 1)/4 \approx 0.309017$ 并不满足上式（代入后两端相差 $0.232$），也不满足 (2) 式。几何上更直接：取这个半径的圆，圆心到抛物线的最短距离是 $0.434$，大于半径 $0.309$，两者根本不相交。

## 结语

答案：$r \approx 0.361027$，圆心 $(0.361027, 0.638973)$，切点 $(0.646632, 0.418133)$。法线共线与 $|TC| = r$ 两步缺一不可；只比较竖直方向的间隙，算到的是圆心到该点切线的距离，而不是圆心到曲线的距离。
