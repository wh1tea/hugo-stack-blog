在 HTML 中直接书写 `<` 或 `&` 时，浏览器并不会将它们作为普通字符显示——这些符号会被解析为 HTML 代码的一部分。要正确显示这些保留字符，必须使用 **HTML 实体**。

## 什么是 HTML 实体

HTML 实体是一种以 `&`（和号）开头、以 `;`（分号）结尾的特殊文本序列。它的作用是告诉浏览器：“请将这段序列解释为对应的普通字符，而非 HTML 标记语法。”

最核心的三个实体（用于转义 HTML 语法符号）为：

| 字符 | 命名实体 | 数字实体（十进制） | 数字实体（十六进制） | 说明                       |
| :--- | :------- | :----------------- | :------------------- | :------------------------- |
| `<`  | `&lt;`   | `&#60;`            | `&#x3c;`             | 小于号，标签起始符         |
| `>`  | `&gt;`   | `&#62;`            | `&#x3e;`             | 大于号，标签结束符         |
| `&`  | `&amp;`  | `&#38;`            | `&#x26;`             | 和号，实体或字符引用的起点 |

除了上述“保命三符号”，实体还有两大用途：

- 表示**不可见字符**，例如不换行空格（`&nbsp;`）。
- 表示**键盘难以直接输入的字符**，如版权符号（`&copy;`）、长破折号（`&mdash;`）、欧元符号（`&euro;`）等。

**实体存在的根本原因**：HTML 是一门标记语言，部分字符在其中承担语法职能。实体是将这些字符从“语法符号”还原为“文本符号”的转义机制。

## 实体的两种写法

HTML 实体有两种形式，可根据场景选用。

### 1. 命名实体（Named Character Reference）

使用易记的英文名称表示字符，例如 `&lt;`、`&gt;`、`&amp;`、`&copy;`。  
**优点**：可读性强，名称易记，书写方便。  
**缺点**：数量有限（约 2000 多个），生僻字符可能没有对应的命名实体。

### 2. 数字实体（Numeric Character Reference）

使用 Unicode 码点表示字符，分为十进制和十六进制两种：

- 十进制：`&#60;`（`<`）、`&#62;`（`>`）、`&#38;`（`&`）
- 十六进制：`&#x3c;`（`<`）、`&#x3e;`（`>`）、`&#x26;`（`&`）

**优点**：命名实体只支持常用特殊符号，而数字实体能表示**任何 Unicode 字符**，不受命名实体数量限制。  
例如，爱心符号 `♥` 没有命名实体，但可写作 `&#x2764;`（十六进制）或 `&#9829;`（十进制）。
**缺点**：可读性较差，需要知道字符的 Unicode 码点

## 常见实体速查表

以下表格列出了日常高频使用的实体，同时给出命名实体和数字实体（十六进制）两种形式，方便对照：

| 字符 | 命名实体   | 数字实体（十六进制） | 说明                                |
| :--- | :--------- | :------------------- | :---------------------------------- |
| `&`  | `&amp;`    | `&#x26;`             | 和号，实体引用的起始符              |
| `<`  | `&lt;`     | `&#x3c;`             | 小于号，标签起始符                  |
| `>`  | `&gt;`     | `&#x3e;`             | 大于号，标签结束符                  |
| `"`  | `&quot;`   | `&#x22;`             | 双引号，属性值的定界符              |
| `'`  | `&apos;`   | `&#x27;`             | 单引号（在某些属性值中需转义）      |
| ` ` | `&nbsp;`   | `&#xa0;`             | 不换行空格（Non‑eaking space）      |
| `–`  | `&ndash;`  | `&#x2013;`           | 短破折号（en dash，宽度约为字母 n） |
| `—`  | `&mdash;`  | `&#x2014;`           | 长破折号（em dash，宽度约为字母 m） |
| `©`  | `&copy;`   | `&#xa9;`             | 版权符号                            |
| `®`  | `&reg;`    | `&#xae;`             | 注册商标符号                        |
| `™`  | `&trade;`  | `&#x2122;`           | 商标符号（TM）                      |
| `≈`  | `&asymp;`  | `&#x2248;`           | 近似等于                            |
| `≠`  | `&ne;`     | `&#x2260;`           | 不等于                              |
| `£`  | `&pound;`  | `&#xa3;`             | 英镑符号                            |
| `€`  | `&euro;`   | `&#x20ac;`           | 欧元符号                            |
| `°`  | `&deg;`    | `&#xb0;`             | 度符号                              |
| `±`  | `&plusmn;` | `&#xb1;`             | 正负号                              |
| `×`  | `&times;`  | `&#xd7;`             | 乘号                                |
| `÷`  | `&divide;` | `&#xf7;`             | 除号                                |

完整的命名字符引用列表可查阅 [HTML Standard: Named Character References](https://html.spec.whatwg.org/multipage/named-characters.html#named-character-references)。

## 结语

HTML 实体是前端开发中最基础也最容易被忽略的知识点。理解其本质——**将具有语法含义的保留字符转义为普通文本**——能帮助你避免页面显示异常、XSS 安全漏洞等常见问题。

**实用建议**：

- 在 HTML 正文中，凡是需要显示 `<`、`>`、`&` 这三个字符，一律使用对应实体。
- 对于属性值中的双引号或单引号，也推荐使用 `&quot;` 或 `&apos;` 转义，避免属性解析错误。
- 遇到特殊符号（版权、商标、货币、数学符号等），优先查找命名实体表；若无对应名称，再使用数字实体。
